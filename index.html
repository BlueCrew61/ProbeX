Broken Object Level Authorization (IDOR) pada Order Service

Ditemukan pada audit heuristik runtime · Vektor API tanpa kepemilikan token sesi valid

01. Ringkasan

Endpoint /api/v2/orders menerima parameter account_id langsung dari query pengguna tanpa memverifikasi hak milik session token pengirim. Penyerang dapat mengganti ID pesanan untuk mengekstrak riwayat transaksi, invoice, dan data alamat pelanggan lain secara masif.

02. Mengapa Berbahaya

Celah ini melewati kontrol otorisasi tingkat objek. Kerugian mencakup pelanggaran privasi data konsumen (GDPR/UU PDP), kebocoran histori belanja kompetitor, dan risiko eksfiltrasi data tanpa meninggalkan anomali pada log autentikasi biasa. Karena request menggunakan kredensial login penyerang yang sah, filter WAF standar seringkali menganggap request ini sebagai lalu lintas normal.
